# A2UI 真实 Agent 改造设计

用户确认：提问 → 大模型理解 → 受限查询工具 → 根据结果生成 A2UI → 前端；追问、点击进入同一 Agent，会计计算由确定代码负责。用户选择 OpenAI 兼容接口。

默认 agent 模式，旧规则仅通过 --mode demo 显式开启。配置 OPENAI_API_KEY、OPENAI_BASE_URL、OPENAI_MODEL，兼容原项目 API_KEY/BASE_URL/MODEL，环境变量覆盖根 .env。不提供未指定的模型默认值。

使用 OpenAI Chat Completions tool calling + JSON 输出。工具 query_sales 只接收月份、区域、视图，不接收 SQL。模型最终输出 reply 和 A2UI components；服务器包裹合法协议 envelope，注入工具结果数据模型。布局由模型决定；数据通过 JSON Pointer 绑定，不允许模型重写表格或金额。支持工具多次调用展示多个月份。

会话由服务器随机标识，通过 X-A2UI-Session 请求/响应头传递；不混入 A2UI 协议。会话保存成功历史、当前组件和工具数据；失败不提交。点击需匹配同会话当前界面实际发出的动作，再交给模型，不直接走固定模板。新会话按钮清除浏览器会话，服务会话空闲 30 分钟回收；最多 64 个会话、12 轮/会话，单轮最多 4 次工具、6 次模型调用及 180 秒。会话内并发请求拒绝。

校验使用官方 Schema、自定义目录、组件图/数据绑定/动作检查；不合法输出允许模型修正一次，失败明确报错，禁止静默模板兜底。原始模型输出、密钥不进入错误响应。界面展示助手答复、会话记录和实际工具调用，不展示内部推理。

验收：实际 SDK 的模拟 HTTP 传输验证函数调用回传；多轮上下文、点击、隔离、失败回滚、未知工具/SQL参数/幻觉金额/越权动作拒绝；既有协议及查询测试回归。真实接口需配置有效凭据；未配置时标注未验收。
